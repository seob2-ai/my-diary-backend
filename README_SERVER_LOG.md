# 서버 로그 확인 방법

## 방법 1: 배치 파일로 서버 실행 (추천)

1. `start_server.bat` 파일을 더블클릭하거나
2. 터미널에서 실행:
   ```bash
   start_server.bat
   ```

이렇게 하면 서버가 실행되면서 로그가 실시간으로 출력됩니다.

## 방법 2: 터미널에서 직접 실행

터미널(PowerShell 또는 CMD)을 열고 다음 명령어를 실행:

```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## 로그 확인 포인트

클라이언트에서 일기 저장을 시도하면 다음 로그가 출력됩니다:

1. **요청 시작**: `요청 시작: POST http://localhost:8000/api/diary`
2. **일기 생성 시작**: `일기 생성 요청 시작: user_id=...`
3. **에러 발생 시**: 
   - `미들웨어에서 예외 발생: ...`
   - `전역 예외 핸들러에서 예외 발생: ...`
   - `ServerErrorMiddleware에서 서버 에러 발생: ...`

## 문제 해결

만약 로그가 보이지 않는다면:
1. 서버가 실행 중인지 확인 (포트 8000이 사용 중인지)
2. 클라이언트가 올바른 URL로 요청을 보내는지 확인
3. 서버를 재시작해보세요
